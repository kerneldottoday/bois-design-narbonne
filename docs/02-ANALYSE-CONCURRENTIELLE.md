**Aucun acteur local ne combine :**
1. Véritable ébénisterie artisanale
2. Site web niveau studio d'architecture
3. Narration projet-first
4. Engagement Répar'acteurs
5. Fabrication locale visible

→ BOIS DESIGN peut occuper le créneau **« atelier de design bois premium »** à Narbonne, distinct des menuiseries PVC et des enseignes cuisines.

4. **S'inspirer de CarmoWood** pour la structure, pas pour le contenu
